# Local IA

# Installation et lancement de **Local IA** sur Linux et Windows :


##  Linux
```bash
git clone https://github.com/lukeclnpro/local_ia.git
cd local_ia
python setup.py

```

---

##  Windows
```powershell
cd $HOME/Documents
git clone https://github.com/lukeclnpro/local_ia.git
cd local_ia
python setup.py

```






# lancement de **Local IA** apres installation :


##  Linux
```bash
cd local_ia
python main.py
```

---

##  Windows
```powershell
cd $HOME/Documents
cd local_ia
python main.py
```

# Desinstallation (seulement a partir de la 0.1.6) :


##  Linux
```bash
cd local_ia
python uninstall.py
```

---

##  Windows
```powershell
cd $HOME/Documents
cd local_ia
python uninstall.py
```



# Information :

### les mise a jour depuis une version inferieur a la 0.0.4 inclu peuvent apporté un manque de fichier du a l'ancienne protection de telechargement. Nous vous conseillons donc de faire la mise a jour normalement, puis d'excecuter 
###  Linux
```bash
cd local_ia
python main.py force_update
```

---

###  Windows
```powershell
cd $HOME/Documents
cd local_ia
python main.py force_update
```

### si vous avez besoin d'aide, excecuter

```bash

```
###  Windows

```powershell
cd $HOME/Documents

python main.py help
```
