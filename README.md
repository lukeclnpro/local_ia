# Local IA

# Installation et lancement de **Local IA** sur Linux et Windows :


##  Linux
```bash
git clone https://github.com/lukeclnpro/local_ia.git
cd local_ia
python setup.py

```

---

##  Windows
```powershell
cd $HOME/Documents
git clone https://github.com/lukeclnpro/local_ia.git
cd local_ia
python setup.py

```
